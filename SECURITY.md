# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, report it responsibly.

**Do not open a public GitHub issue.**

Instead, if you have questions, reach out to technical support or post on the Hamilton discourse.

**[Join the Hamilton Robotics Discussion Platform](https://discourse.hamiltoncompany.com/c/our-software/python-sdk)**

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

| Step | Timeframe |
|------|-----------|
| Acknowledgement | Within 3 business days |
| Initial assessment | Within 7 business days |
| Fix or mitigation | Dependent on severity |

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0 | ✅ |
| 0.x | ❌ |

## Disclosure Policy

We follow [coordinated vulnerability disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure).
Security fixes will be released as patch versions and documented in the [CHANGELOG](CHANGELOG.md).
